# 本番：久米島 警報情報（自販機 640×192）

## 起動

```bash
npm start
```

または `start.bat`

- 本番: http://127.0.0.1:8080/
- デモ: http://127.0.0.1:8080/?demo=1

## 構成

| ファイル | 役割 |
|----------|------|
| `index.html` | 本番画面 |
| `css/display.css` | 表示スタイル |
| `css/base.css` | 共通サイズ |
| `js/app.js` | 表示・切替ロジック |
| `js/warnings.js` | 気象庁データ解析 |
| `js/warning-codes.js` | 警報コード |
| `js/config.js` | 設定 |
| `server.mjs` | 静的配信＋気象庁プロキシ |
