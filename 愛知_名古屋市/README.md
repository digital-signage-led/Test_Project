# アラートキューブ V2.0（名古屋市）

4面 512×128。社名・ロゴなし。現場の位置は `config/site-config.js` です。

```
index.html     サイネージ本体
sw.js          オフライン用キャッシュ
config/        現場設定
scripts/       動き
styles/        色と文字
images/        気象庁の天気アイコン
```

## 起動

```
npx --yes serve -l 3200
```

`http://127.0.0.1:3200/`
