## 1. 画面の基本仕様

| 項目 | 仕様 |
|------|------|
| 表示サイズ | **512×128 px**（128×128 パネル×4列＝4面） |
| 文字優先 | 大きな文字テロップを優先 |
| 通常運用 | **発表があるときだけ**表示。未発表は黒画面 |
| 出典表記 | 出典：気象庁・環境省データ（各防災画面のフッタ） |

### 1.1 表示の流れ（発表時のみ）

```
（発表なし）黒画面待機
     ↓ 発表あり
緊急地震（直後1分）→ 熱中症アラート → 避難情報 → 気象警報・注意報 →（発表継続中は繰り返し）
```

発表がすべて解除されたら黒画面に戻る。

---

## 2. 防災表示 — 何を・いつ表示するか

**共通ルール**

1. **発表されている項目だけ**表示する  
2. 解除・未発表は表示しない  
3. 発表が続いている間は繰り返し再表示する  

---

### 2.1 気象警報・注意報（sceneRainWarn）

**既定（`bosaiOnly`）:** `led.html` と同じく、発表中の警報・注意報を**1件ずつ**色付き3段テロップで順送りする。

| 帯 | 表示内容 |
|----|----------|
| 上帯 | 「久米島の地域で発表されています」／発表時刻／当該種別 |
| 中央帯 | いま表示中の警報・注意報名（右→左スクロール） |
| 下帯 | 注意報／警報／危険警報／特別警報 |

まとめ表示（全発表を中央帯に並べる）に戻すときは `?rainwhite=1`。

警戒レベル対象4種（河川氾濫・大雨浸水・土砂・高潮）とその他気象15種。発表時のみ。

---

### 2.2 避難情報／熱中症アラート／地震

自治体避難・環境省熱中症アラート・緊急地震速報は、いずれも**発表時のみ**表示。
