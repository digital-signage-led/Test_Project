## ほかのAIへの依頼文（このまま使う）

```
あなたへの依頼です。

【目的】
株式会社エステックの LED サイネージ（640×128・5面）を、新しい会場向けに展開する。
見た目・デザイン・ループ・HTML/CSS/警報ロジックは一切変更しない。
変えてよいのは位置情報（site-config.js）だけ。

【やること】
1. 下の「完成ファイル：assets/site-config.js」を、新しい会場の値で埋める

3. 出力は site-config.js の中身だけ（1ファイル）
4. デザイン変更・CSS変更・index.html の見た目変更は禁止

【新しい会場の情報】

会場名:
住所:
表示地名（短い）:
都道府県:
```

## ルール（厳守）

- **デザインを変えない**（色・字サイズ・帯・余白・フォント・縁・アニメ）
- **index.html / CSS / warning-hero.js を触らない**
- **変えるのは `assets/site-config.js` だけ**
- WEB と LED で見た目を分岐しない
- 警報は気象庁 r8: `https://www.jma.go.jp/bosai/warning/data/r8/{warnArea}.json`

### 手順（人側）

1. フォルダ一式をコピー（例: `横浜_エステック_展示会`）
2. 下の完成 JS を `assets/site-config.js` に保存（上書き）
3. Ctrl+F5 で確認
4. 本番へは `index.html` + `assets/` をまとめて上げる

## 必須項目一覧

| 項目 | 役割 | 幕張の例 |
|------|------|----------|
| `site.label` | 時刻下白帯の会場名 | 幕張メッセ |
| `site.locationLabel` | 天気パネル等の短い地名 | 幕張 |
| `moe.point` | 環境省 WBGT 地点コード | 45212 |
| `moe.pointName` | 環境省の観測地点名 | 千葉 |
| `moe.alertArea` | 熱中症アラートの府県名 | 千葉県 |
| `moe.region` | 環境省 region | 04 |
| `moe.prefecture` | 環境省 prefecture | 12 |
| `jma.amedasPoint` | AMeDAS（通常は moe.point と同じ） | 45212 |
| `jma.forecastArea` | 予報区域コード | 120000 |
| `jma.forecastLabel` | 予報表示名 | 幕張 |
| `jma.warnArea` | 警報の都道府県コード | 120000 |
| `jma.warnCity` | 警報の市町村コード | 1210000 |
| `jma.warnCityLabel` | 警報上段の市町村名 | 千葉市 |

任意: `site.address` / `geo` / `customer`

## 完成ファイル：assets/site-config.js（★を埋めてこのまま保存）

下のコードブロックをコピー → `assets/site-config.js` に貼り付け。  
★ の値だけ新しい会場に書き換える。

```javascript
/**
 * 現場設定（位置情報だけ書き換え）
 * デザイン・HTML・CSS・ループは触らない。このファイルだけ変える。
 */
(function (global) {
  'use strict';

  var cfg = {
    site: {
      customer: '株式会社エステック',
      rental: '',
      /* ★ 時刻下白帯に出る会場名 */
      label: '（会場名）',
      /* ★ 備考用住所 */
      address: '（住所）',
      /* ★ 予報・天気パネル下の短い地名（例: 幕張 / 横浜） */
      locationLabel: '（表示地名）'
    },
    moe: {
      /* GAS は共通。地点は point で切替 */
      gasUrl:
        'https://script.google.com/macros/s/AKfycbzSTsappgfJTaJruOBJsbnCXSTPkeTBp39CXpvoSZsPQ0mWGs4KjSonC8_eZ2b1EeUXTQ/exec',
      /* ★ 環境省 WBGT 5桁地点コード（必須・会場最寄り） */
      point: '00000',
      fallbackPoint: '',
      /* ★ GAS/CSV 用の観測地点名（環境省表記） */
      pointName: '（観測地点名）',
      /* ★ 熱中症アラートの府県名（例: 千葉県） */
      alertArea: '（都道府県）',
      /* ★ 環境省 region / prefecture */
      region: '00',
      prefecture: '00'
    },
    jma: {
      /* ★ 気象庁 AMeDAS（通常は moe.point と同じ） */
      amedasPoint: '00000',
      amedasSupplementPoint: '',
      /* ★ 予報区域コード（例: 千葉県 120000） */
      forecastArea: '000000',
      /* ★ 予報表示名（locationLabel と同じでよい） */
      forecastLabel: '（表示地名）',
      /* ★ 警報 JSON の都道府県コード（例: 120000） */
      warnArea: '000000',
      /* ★ 警報の市町村コード（例: 千葉市 1210000） */
      warnCity: '0000000',
      /* ★ 警報上段に出る市町村名（例: 千葉市） */
      warnCityLabel: '（市町村名）'
    },
    /* ★ 会場座標（任意） */
    geo: { lat: 0, lon: 0 },
    timeZone: 'Asia/Tokyo',
    refreshMs: 60000,
    footSource: '出典：気象庁・環境省データ'
  };

  global.SignageConfig = cfg;

  global.SIGNAGE_CONFIG = {
    logoSrc: './assets/estec_logo.png?v=1',
    logoAlt: '株式会社エステック',
    logoPanelBg: '#ffffff',
    logoCorpSrc: '',
    footLogoSrc: '',
    footBannerSrc: './assets/estec_foot_lockup.png?v=2'
  };
})(typeof window !== 'undefined' ? window : global);
```
