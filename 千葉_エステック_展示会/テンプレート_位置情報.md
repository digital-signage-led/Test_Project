# 現場テンプレート（位置情報だけ差し替え）

**一括コピペ用のまとめはこちら → [`テンプレート_一括コピペ.md`](./テンプレート_一括コピペ.md)**  
（依頼文・ルール・幕張例・空欄の `site-config.js` が1ファイルに入っています）

見た目・ループ・警報／天気／WBGT の仕組みは共通です。  
**変えるのは位置情報（`assets/site-config.js`）だけ**です。デザインは変えないでください。

## 新しい会場を作る手順

1. このフォルダ一式をコピーする（例: `横浜_エステック_展示会`）
2. `テンプレート_一括コピペ.md` の「完成ファイル」を `assets/site-config.js` に保存
3. ★ 項目だけ書き換える（またはほかのAIに会場情報と一緒に一括コピペを渡す）
4. ローカルで `index.html` を開いて確認（Ctrl+F5）
5. 本番へは `index.html` + `assets/` をまとめて上げる

`index.html` 本体や CSS / JS のロジックは触らない。

## 関連ファイル

| ファイル | 用途 |
|---------|------|
| `テンプレート_一括コピペ.md` | **ほかのAIに渡す用（全文コピー）** |
| `assets/site-config.js` | 本番が読む設定（幕張の値） |
| `assets/site-config.template.js` | 空欄雛形（単体） |
