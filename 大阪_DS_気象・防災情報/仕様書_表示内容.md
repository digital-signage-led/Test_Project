# 大阪 DS 気象・防災情報 — 表示仕様書

| 項目 | 内容 |
|------|------|
| 対象システム | 大阪 DS 気象・防災情報（320キューブ / 4面 LED） |
| 設置想定 | 〒559-0024 大阪府大阪市住之江区新北島１丁目７ |
| 本番ファイル | `index-4face.html` |
| デモ入口 | `demo.html` / `demo-quake.html`（地震）・`demo-bousai.html`（警報テロップ） |
| 基準日 | 2026年5月（新たな防災気象情報・警戒レベル化）対応 |

---

## 1. 画面の基本仕様

| 項目 | 仕様 |
|------|------|
| 表示サイズ | **512×128 px**（128×128 パネル×4列＝4面） |
| 文字優先 | 図より大きな文字テロップを優先 |
| 通常運用 | 時刻・観測・WBGT・予報などをループ再生 |
| 防災割り込み | **発表があるときだけ**通常ループを中断して表示。未発表は出さない |
| 出典表記 | 出典：気象庁・環境省データ |

### 1.1 通常ループの流れ

```
① 時刻＋下帯 → ② 気象観測 → ③ 暑さ指数(WBGT) → ④ 4日予報 → ⑤ 多言語WBGT指針 → ①へ
```

発表がある場合、ループ末尾付近で次を割り込み（該当時のみ）:

```
熱中症アラート → 避難情報 → 気象警報・注意報 → （地震は直後1分単独／その後ループに統合）
```

## 3. 防災割り込み — 何を・いつ表示するか

**共通ルール**

1. **発表されている項目だけ**表示する  
2. 解除・未発表は表示しない  
3. 発表が続いている間は、通常ループの合間にも再表示する  

---

### 3.1 気象警報・注意報（sceneRainWarn）

#### 見た目（既定：白ベース3段）

| 帯 | 高さ | 表示内容 |
|----|------|----------|
| 上帯 | 40px | 「住之江区の地域で発表されています」／発表時刻／発表中の種別まとめ |
| 中央帯 | 約50px | **発表中の警報・注意報名**を右→左にスクロール |
| 下帯 | — | 発表中の段階だけ（注意報／警報／危険警報／特別警報） |

スクロール順: **注意報 → 警報 → 危険警報 → 特別警報**

### 3.4 地震（sceneQuake）

| フェーズ | 時間・回数 | 見た目 | 表示内容 |
|----------|------------|--------|----------|
| **直後** | 約1分 | 黒背景＋赤帯＋黄アイコン | 「緊急地震速報」／「○○で地震発生　震度X　MX.X（気象庁）」 |
| **その後** | 通常ループに **3周** | 観測パネル | 震源・マグニチュード・深さ・震度。フッタ「出典：気象庁」「住之江区」 |

| デモ種別 | 意味 |
|----------|------|
| `quake=warn` | 警報（黒ティッカー） |
| `quake=eew` | 予報・緊急地震速報 |
| `quake=info` | 地震情報（情報種別の表示） |

入口: `demo.html` / `demo-quake.html`

| リンク | URLの要点 |
|--------|-----------|
| ① 直後1分・黒ティッカー（警報） | `?only=quake&quake=warn&native640=1` |
| ② 直後1分・黒ティッカー（予報） | `?only=quake&quake=eew&native640=1` |
| ③ 通常ループ＋割り込み | `?quake=warn&native640=1` |
| ④ 地震情報デモ | `?only=quake&quake=info&native640=1` |

無効化: `?quake=0` または `?noquake=1`

## 6. 表示の優先と「出さない」条件

| 状態 | 動作 |
|------|------|
| 気象警報・注意報が発表中 | 発表中の項目名だけをスクロール表示 |
| すべて解除／未発表 | 気象警報シーンを**出さない**（通常ループのみ） |
| 避難情報なし | 避難シーンを**出さない** |
| 熱中症アラートなし | 熱中症シーンを**出さない** |
| 地震なし | 地震シーンを**出さない** |
| 複数発表 | 注意報→警報→危険警報→特別警報の順で流す。画面の強調色は最上位段階 |

## 8. 用語の整理

| 用語 | 意味 |
|------|------|
| 警戒レベル | 避難行動の目安（1〜5）。気象庁情報の対象は河川氾濫・大雨浸水・土砂災害・高潮の4種 |
| 避難情報 | 市町村が発令（高齢者等避難／避難指示／緊急安全確保） |
| 危険警報 | 2026年改定でレベル4相当として新設された段階 |
| 発表中のみ表示 | サイネージは「今出ている情報」だけを流し、無いときは防災テロップを出さない |
